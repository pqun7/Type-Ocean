# Website Sections
1. Home Page
    - At the top, there is a typing practice similar to Monkeytype
    - below it are the website sections:
        1. code typing practice 
        2. normal typing practice
        3. Focus & Distraction Training
            🔹 Simulates real-world distractions (e.g., background noise, pop-ups).
            🔹 Trains users to type accurately even under stress.
            🔹 Includes a "no backspace" challenge to improve confidence.
        4. Historical & Literature Typing
            🔹 Type classic literature passages from books like Moby Dick or 1984.
            🔹 Learn about historical documents by typing them out.
            🔹 Encourages both reading comprehension and typing speed.
        5. Typing Games & Challenges
            🔹 Multiplayer mode: Compete with others in typing duels.
            🔹 Mini-games like "Word Bomb" (where words explode if you don’t type them fast enough).
            🔹 Survival Mode: Type continuously without making mistakes to stay in the game.


    - There is also an online section with options to play with random people or with friends.

2. Training Section
    - Each section consists of levels, and the number of levels depends on the section.
    - In all sections, there are categories based on the level.
        1. Normal: It only trains you
        2. Flash: To pass, you need to reach a certain speed.
        3. Hunter: To pass, you need to achieve a certain accuracy.
        4. Joker: To pass, you need to achieve both speed and accuracy.

3.  Gamification & Rewards
    - XP & Leveling System: Earn XP from typing sessions and level up.
    - Achievements & Badges: Unlockable milestones like "100 WPM Club" or "Accuracy Master."
    - Typing Streaks: Users are rewarded for maintaining daily practice.

4. Fun & Experimental Modes
    - Reverse Typing Mode: Type words backward for a challenge.
    - Invisible Typing: Typed text disappears after a few seconds, forcing memorization.
